This release contains several major upgrades.

<ul>
  <li>
    Overhauled clinical audit with a much richer analysis of payer-specific
    policies.
  </li>
  <li>
    Patients demographic information is now fetched in real-time using FHIR
    API integration.
  </li>
  <li>
    Full automated support for more payers and utilization managers, including
    Cohere, Evicore, Evolent, etc.
  </li>
  <li>Support for modifiers, add-on codes and quantities per CPT.</li>
</ul>
